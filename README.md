# 📊 A股自动分析 & 微信推送

每个交易日收盘后自动运行技术分析，通过方糖推送到微信。

**🔥 零外部依赖** — 全部使用 Python 内置模块，无需安装任何第三方库。

## 功能

- 📈 **技术指标**：MA均线/RSI/MACD/布林带/量价分析
- 🎯 **波段策略**：综合多指标给出买入/观望/回避信号
- 📱 **微信推送**：方糖ServerChan，收盘后自动推送到手机
- ⏰ **定时运行**：GitHub Actions，每个交易日18:00自动执行
- 🔧 **可扩展**：JSON/YAML配置，加减股票只改一行
- 🪶 **零依赖**：仅用Python标准库，GitHub Actions和本地均可直接运行

## 快速开始

### 1. 注册方糖 & 获取 SendKey

1. 访问 [方糖 ServerChan](https://sct.ftqq.com/) → 微信扫码登录
2. 复制你的 **SendKey**（页面顶部就能看到）

> 免费版每天可推送 5 条消息，完全够用

### 2. Fork 本项目

```bash
# GitHub 页面点 Fork，或者：
git clone https://github.com/你的用户名/stock-analyzer.git
cd stock-analyzer
```

### 3. 配置 Secrets

在 GitHub 仓库页面：
**Settings → Secrets and variables → Actions → New repository secret**

| Name | Value |
|---|---|
| `SERVERCHAN_SENDKEY` | 你的方糖 SendKey |

### 4. 配置股票列表

编辑 `config.json`：

```json
{
  "stocks": [
    {"code": "002170", "name": "芭田股份", "market": "sz"},
    {"code": "600519", "name": "贵州茅台", "market": "sh"},
    {"code": "300750", "name": "宁德时代", "market": "sz"}
  ],
  "analysis": {
    "kline_days": 120
  }
}
```

> market: `sh`=上海, `sz`=深圳, `bj`=北京

### 5. 手动测试

在 GitHub 仓库页面：
**Actions → Daily Stock Analysis → Run workflow → Run workflow**

等待1-2分钟，查看微信是否收到推送。

### 6. 完成 🎉

之后每个交易日18:00会自动运行。也可以在本地运行：

```bash
# 无需安装任何依赖！直接用 Python 内置模块
set SERVERCHAN_SENDKEY=你的SendKey    # Windows
export SERVERCHAN_SENDKEY=你的SendKey  # Linux/Mac

python run_daily.py        # 推荐：分析 + 老龙反抽 + 郑希研报 + 推送
python analyzer.py         # 只跑自选股技术面（推送正文与上面同款）
```

## 信号说明

| 信号 | 含义 | 触发条件 |
|---|---|---|
| 🟢 强烈买入 | 趋势、动能、资金共振 | 评分 ≥ 50 **且** 均线多头 **且** RSI<70 **且** 资金不流出 |
| 🔹 偏多 | 多头因子占优 / 高分但确认不足 | 25 ≤ 评分 < 50（或够 50 分但缺上面任一确认） |
| 🟡 观望 | 多空力量接近 | -25 < 评分 < 25 |
| 🔴 偏空 | 空头因子占优 | -50 < 评分 ≤ -25 |
| ⚠️ 回避 | 趋势与动能同步走坏 | 评分 ≤ -50 |

评分由五个维度加权而成：趋势 ±36、动能 ±30、位置 ±25、量价 ±10、资金 ±12。
**超买/超卖按趋势方向解读**——上升趋势里的超买不扣分，下跌趋势里的超卖也不加分（避免接飞刀）。

### 为什么「强烈买入」要卡这么死

本自选池 150 个交易日、1885 个样本、前瞻 5 日的回测（`python scripts/backtest_signals.py`）：

| 口径 | 样本 | 5 日超额 | 胜率 |
|---|---|---|---|
| 评分 ≥50（旧口径） | 217 | +1.01% | 51.2% |
| 评分 ≥50 + 多头排列 + RSI<70 + 资金不流出 | 59 | **+2.80%** | **69.5%** |
| 评分 25~50（「偏多」） | 402 | **-0.77%** | 45.5% |

- 新口径去极值后超额 +2.28%，逐股留一（去掉任意一只票）超额仍全为正，前后半段 +1.30% / +3.01%
- 「偏多」档三段行情全为负，**它不是买点**，只用来做强弱排序，所以推送里和「强烈买入」分开展示
- 评分 ≥50 但 RSI ≥70 的样本 5 日中位数 -1.10%——评分高不等于能买，均线没走多头、已经过热、
  资金在流出，都属于「看着强但没人接」，一律降级观察
- 单笔风险按买点 -6% 封顶，盈亏比不足 1.5 会标注「偏低，仓位减半」
- ⚠️ 样本只有 8~13 只自选票、7 个月，属于小样本，结论会随行情漂移，别当铁律

## 数据来源

- **腾讯财经 API**：实时行情、日K线（前复权）
  - 注意：接口内嵌的 62/70/71 号字段是「年初至今/20日/60日涨跌幅」，**不是资金流向**
- **资金流向**：东方财富 `push2his.eastmoney.com` 的 `fflow/daykline/get`（主力/大单/超大单/中单/小单全口径）
  - ⚠️ 只有 `push2his` 这个域名给历史数据（`push2` / `push2delay` 只返回 1 行），
    路径必须是 `fflow/daykline/get`；写错的话请求会 200 但拿不到数据，静默退化成新浪口径
  - 备用源：新浪资金流（超大单口径），东财不可用时自动切换并在推送中如实标注口径
  - 两个源都失败时自动隐藏资金相关内容，不会输出错误数据
  - 东财按 IP 限频，连续失败会熔断该域名一段时间（正常现象，会自动走备用源）
- 支持沪深京全部交易所

## 推送格式

推送正文由 `push_format.py` 生成，刻意只使用纯文本 + emoji + 【】分节。
微信服务号卡片的渲染有三条硬约束，排版就是围绕它们设计的：

1. **单个换行会被吞掉**——正文里用 `\n` 分行的内容在卡片里会被拼成一整段，
   只有**空行**才真的换段。所以段与段之间统一用 `\n\n`（`push_format.PARA`）拼接，
   「一行一件事」必须靠空行隔开，否则读起来就是一堵墙。
2. **Markdown 不渲染**——`**加粗**`、`#` 标题、表格、`- ` 列表在卡片端会露出原始符号
   （详情页才渲染），所以全篇走纯文本 + emoji + 【】。
3. **一行约 22 个汉字**——单段控制在 1~2 行，宁可多分段不要长句。

实际效果（数字为示意）：

```
📊 9月19日复盘｜13只·买入2偏多3

【大盘】上证 3821.44 +0.35%｜深成 12488.10 +0.92%｜创业板 2673.55 +1.44%

【自选】涨4 跌3 平0，均幅 +0.44%｜买入2 偏多2 观望1 偏空2

【今日变化】3只

🔺 中国电影 观望→强烈买入 +1.3%｜均线多头排列，趋势向上

【值得关注】

🟢 强烈买入 中国电影（600977） +62分

12.93 +1.33%｜RSI 57｜量比 0.6｜主力净流入768万（连3日）

买点 12.60｜止损 12.10｜目标 13.90｜盈亏比 2.6

【自选全览】

🟢 强烈买入 · 中国电影 +62 · 牧原股份 +55

🔹 偏多 · 翔鹭钨业 +88 · 芭田股份 +38

🔴 偏空 · 劲旅环境 -32 · 华纬科技 -58

【老龙反抽】扫描22只，入选4只

【郑希观点】

———— 仅供复盘参考，不构成投资建议
```

- 「今日变化」优先于「今日状态」，避免每天推送内容雷同；降级条目只引用 ❌/⚠️ 的理由
- 「值得关注」里只有「强烈买入」才给买点/止损/目标，偏多档不给可执行价位
- 资金流数据若滞后于行情日期，行内标注〔截至 MM-DD〕，不把旧资金当当天
- 顶部日期为**行情数据日期**（周末/节假日运行不会误标成当天）
- 郑希观点语料超过 60 天未更新时自动隐藏该板块
- 每次运行都会把真正推出去的正文存到 `reports/push_YYYY-MM-DD.md` 并随日报归档

### 本地预览排版（不发送）

```bash
PUSH_DRY_RUN=1 python run_daily.py     # Linux/Mac
set PUSH_DRY_RUN=1 && python run_daily.py   # Windows cmd
```

只生成正文并打印预览，不调用方糖；不配 `SERVERCHAN_SENDKEY` 时同样只生成不发送。

## 注意事项

- GitHub Actions cron 有最多 15 分钟延迟
- 法定节假日仍会触发（但数据为上一交易日）
- 东方财富 API 有频率限制，多只股票间隔 1 秒
- 方糖免费版每天 5 条，多只股票合并为 1 条推送
- **技术分析仅供参考，不构成投资建议**

## 扩展

### 添加更多股票

编辑 `config.yaml` 的 `stocks` 列表即可，支持无限添加。

### 调整推送时间

编辑 `.github/workflows/daily-analysis.yml` 的 cron 表达式：
```
# UTC 时间，比北京时间少 8 小时
# 例：北京时间 18:00 = UTC 10:00
- cron: '0 10 * * 1-5'
```

### 本地定时运行（不用 GitHub Actions）

```bash
# Windows 任务计划程序
# Linux crontab
30 15 * * 1-5 cd /path/to/stock-analyzer && python analyzer.py
```
